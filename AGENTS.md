# AGENTS.md — Ficool SEO Content Autopilot

## Mission
Build data-driven Vietnamese SEO content for Ficool, a local refrigeration/HVAC service business in Ho Chi Minh City.

## Operating rules
- Read relevant config and knowledge files before planning or writing.
- Never invent business facts, prices, case studies, reviews, credentials, statistics, or service claims.
- Default WordPress publishing mode is `draft`.
- Research before writing; a content brief is required before article generation.
- Image Planner decides whether an image adds information; do not generate decorative images unnecessarily.
- Every generated image needs contextual placement and SEO metadata.
- Internal links must be semantically relevant and support funnel progression.
- Run SEO, GEO, Local SEO, conversion, and technical QA before WordPress handoff.
- Treat structured artifacts as contracts between skills.
